# Al Brooks Price Action Summaries

这是一套以中文整理的 Al Brooks 价格行为课程学习笔记，保留关键英文术语、条件边界、决策逻辑和视觉核验结论，方便系统复习与知识检索。

## 仓库内容

- `00_课程总索引.md`：课程覆盖范围、主题和 QA 状态总览。
- `01_价格行为概念库.md`：跨课程概念、定义、边界与关联。
- `02_形态与交易决策树.md`：从市场状态到交易决策的结构化路径。
- `03_疑问_冲突_易错点.md`：翻译偏差、冲突、未决问题与常见误用。
- `summaries/`：各课程的知识型总结。

课程覆盖范围与当前状态见 [课程总索引](00_课程总索引.md)。详细来源、字幕、视觉时间线和 QA 审计台账属于私有工作记录，不在公开仓库中发布；正文中指向这些台账的链接仅保留为来源说明，不会在 GitHub 上解析。

## 内容边界

- 不包含原始视频、字幕、课件、音频、提取帧或本地处理工具。
- 笔记中的概率和经验阈值主要是课程主张；除非明确说明，否则未经过独立统计验证。
- 内容仅供学习和研究，不构成投资建议、交易信号或收益承诺。
- Al Brooks 姓名及相关课程内容的权利归原权利人所有；本仓库只发布独立整理的学习笔记。
